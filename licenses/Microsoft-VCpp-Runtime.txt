Microsoft Visual C++ Redistributable runtime (MSVCP140.dll, VCRUNTIME140.dll, VCRUNTIME140_1.dll)

These binaries are the Microsoft Visual C++ 2022 x64 redistributable runtime, deployed beside the
application because the shared Swift bridge and several native dependencies link against the
Microsoft C++ runtime.
