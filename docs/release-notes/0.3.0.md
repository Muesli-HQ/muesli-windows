## Muesli for Windows 0.3.0

The first build of Muesli for Windows published on GitHub: local-first dictation and meeting transcription, as a native Windows app.

- **Dictation anywhere.** Hold your global shortcut, speak, release, and the transcript is pasted into the active app. A floating indicator shows when the microphone is live.
- **Meeting recording and notes.** Capture your microphone and the meeting audio as separate tracks, transcribe locally, review speaker labels, and generate notes.
- **On-device transcription.** Choose from offline Parakeet, Whisper, SenseVoice, Qwen3-ASR and Cohere models. Models download only when you prepare them, into `%USERPROFILE%\.cache\muesli`.
- **Optional hosted providers.** Use your own OpenAI, OpenRouter or Anthropic key for meeting notes or hosted dictation if you want to; nothing is sent unless you set one up.
- **Local library.** Search dictations and meetings, organise them in folders, keep a personal dictionary, and export to Markdown or PDF.

### A few details

This is a beta. Transcription runs on the CPU by default. Live meeting transcription is off until you turn it on. Updates are manual: install a newer release over this one.
