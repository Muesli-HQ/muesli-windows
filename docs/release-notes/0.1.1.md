## Muesli for Windows 0.1.1

A small follow-up to 0.1.0 that fixes the installer for the unsigned developer build. The app itself is unchanged.

- **Installing over an existing copy works.** The 0.1.0 install script stopped with an error when Muesli was already registered on the PC, unless it was run with `-Force`. It now asks whether to replace the existing copy and carries on.

### A few details

This is a beta. If you installed 0.1.0, run the 0.1.1 install script to update; your history and settings are kept. Updates are manual.
